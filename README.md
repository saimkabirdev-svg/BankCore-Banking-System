**BankCore — Banking System**



BankCore is a Python-based banking system backend project developed using Object-Oriented Programming (OOP) principles. It simulates basic banking operations through a structured, modular, and object-oriented approach.



The project demonstrates how Python OOP concepts can be applied to build a simple banking system with different account types and transaction management.



Features



\- Account Creation: Create and manage bank accounts.

\- Deposit Money: Add funds to an existing account.

\- Withdraw Money: Withdraw funds while validating account balance.

\- Transaction History: View the transaction records of an account.

\- Multiple Account Types: Supports Savings Accounts and Current Accounts.

\- Balance Management: Maintain and update account balances.

\- Input Validation: Handle invalid operations and prevent unauthorized transactions.



**Object-Oriented Programming Concepts**



This project implements the following OOP concepts:



\- Classes and Objects: Organizing banking operations into reusable classes.

\- Encapsulation: Protecting account data and controlling access to account balances.

\- Inheritance: Using a base `Account` class for specialized account types.

\- Method Overriding: Implementing account-specific behavior in derived classes.

\- Polymorphism: Supporting different account behaviors through a common interface.



Technologies Used



\- Python 3

\- Object-Oriented Programming (OOP)
